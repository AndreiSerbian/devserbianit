# Пересборка логотипа AS по присланному эскизу

Знак перерисовывается заново по фото: залитая арка «A» с прорезью и перекладиной, «S» из скруглённых шлейфов. Разделитель убираем, цвета — только токены сайта.

## Знак

**A — залитая арка.** Замкнутый path на сетке 64x64: прямоугольная снизу форма с полукруглым верхом, внутри — вертикальная прорезь-«язык» (тоже с закруглённым верхом), которую пересекает горизонтальная перекладина. Заливка, а не штрих; ножки обрезаны по базовой линии.

**S — шлейф.** Форма из эскиза: скруглённая полоса, идущая от верхнего правого терминала влево, вниз через среднюю перемычку и в нижний левый терминал. Терминалы — короткие прямоугольные «коннекторы» с закруглением.
- `full` — три вложенных контура шлейфа (внешний, средний, внутренний) с разной прозрачностью, плюс оба терминала.
- `compact` / `micro` — один контур, терминалы упрощены (micro — без них), толщина увеличена для читаемости от 16 px.

**Цвет.** Красно-синий градиент из эскиза переводится в палитру бренда: градиент по A от `--teal-bright` к `--primary` (в light-режиме — к `--teal-deep`), перекладина — `--cream`, S — `--cream` со ступенчатой прозрачностью слоёв. Тон `light` — всё cream, `dark` — graphite, `mono` — `currentColor`. Все значения через `hsl(var(--...))`.

**Разделитель.** Вертикальная черта между A и S не используется ни в одном варианте; A и S ставятся плотнее, оптический зазор выравнивается вручную.

## Что меняется в коде

- `src/components/brand/ASMonogram.tsx` — полностью новая геометрия: `A_SHAPE` (заливка + прорезь через `fill-rule`), `BAR`, `S_OUTER/S_MID/S_INNER`, терминалы. Публичный API (`variant`, `size`, `tone`/`theme`, `title`, `decorative`, `className`) сохраняется, поэтому места использования не ломаются.
- `src/components/brand/BrandLockup.tsx` — подгонка размеров и оптического отступа между знаком и текстом под новые пропорции; логика full/compact остаётся.
- `src/components/hero/RevolverHeroDiagram.tsx` — центральный хаб продолжает использовать `micro`, проверяем что новая форма не спорит с окружностью хаба.
- `public/favicon.svg`, `favicon.ico`, `favicon-16/32`, `apple-touch-icon.png`, `icon-192/512.png` — перегенерация из нового micro-варианта; `site.webmanifest` и `index.html` при необходимости.

## Проверка

QA-страница `/__brand-check` и скрипт `scripts/qa/monogram-crop-check.py` уже есть — прогоняем: 16/32/48/96 px, 4 тона, WebKit + Chromium, iPhone/iPad/Pixel. Критерии: нет выхода за viewBox, прорезь A видна на 16 px, слои S не сливаются в пятно, шапка и футер без сдвига раскладки.

## Технические детали

- Один `viewBox="0 0 64 64"`, `preserveAspectRatio="xMidYMid meet"`, без фильтров и внешних ID; градиент — inline `<linearGradient>` с id, стабилизированным через `useId`, чтобы несколько экземпляров на странице не конфликтовали.
- Слои S задаются одним общим path с разной шириной штриха и прозрачностью — без дублирования геометрии.
- PNG/ICO рендерятся из SVG в песочнице, кладутся в `public/` как реальные файлы.
