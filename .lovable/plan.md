# Логотип AS — новая система знака

Только логотип и его интеграция. Hero, услуги, кейсы и форма не меняются.

## Что будет сделано

### Знак
Монограмма AS перерисовывается вручную как inline React SVG на одной сетке 64x64:
- **A** — перевёрнутая U-образная арка с центральной перекладиной, читается как буква, перекладина сливается с ножками (не «кнопка»).
- **S** — плотная линия-кабель с двумя простыми терминалами на концах; толщина подобрана так, чтобы визуальный вес совпадал с A.
- Вертикальный разделитель — только в расширенном lockup, тоньше и тусклее букв.

Три варианта детализации:
1. `full` — арка в сдержанном двухтоновом тиле, лаймовая перекладина, S кремовая, два терминала.
2. `compact` — те же пропорции, один тон на A, терминалы убраны, штрихи чуть толще (шапка, мобильная навигация).
3. `micro` — только силуэт AS: арка + перекладина + S, без терминалов и разделителя, максимально толстые штрихи для 16–32 px.

Цветовые режимы: `brand` (токены темы), `light` (для тёмного фона), `dark` (для светлого фона), `mono` (`currentColor` — печать и техслучаи). Все цвета — только через `hsl(var(--...))`, без хардкода.

### Компоненты
- `src/components/brand/ASMonogram.tsx` — `variant`, `size`, `tone`, `className`, `title`, `decorative`.
- `src/components/brand/BrandLockup.tsx` — `orientation` (horizontal/stacked), `showDescriptor`, `compact`, `tone`, `className`. Текст: ANDREI SERBIAN / IT SOLUTIONS (Oswald + Golos).
- `src/components/brand/index.ts` — единая точка импорта.

Доступность: рядом с видимым текстом — `aria-hidden`; отдельно — `role="img"` с локализованным title («Логотип Andrei Serbian» / «Andrei Serbian logo» / «Logo Andrei Serbian») из словарей переводов.

### Интеграция
- Шапка на главной и на странице калькулятора — `BrandLockup` с `compact`.
- Футер — полный `BrandLockup` (full-монограмма + дескриптор).
- `HeroDiagram`: в центральный узел схемы подставляется `micro`-монограмма, остальной Hero не трогаем.
- Старый `Monogram.tsx` остаётся в репозитории до подтверждения, но все его вызовы заменяются.

### Favicon и иконки
Из micro-варианта генерируются: `favicon.svg`, `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`; `site.webmanifest` обновляется под новый набор. Ссылки в `index.html` обновляются. Проверка читаемости на тёмной и светлой вкладке при 16 и 32 px.

### Проверка
Playwright-скриншоты: знак на 16/32/48/96 px, на тёмном и светлом фоне, шапка, футер, lockup. Плюс проверка отсутствия горизонтального overflow, ошибок TS и консоли. Публикация не выполняется.

## Технические детали
- SVG: `viewBox="0 0 64 64"`, без фиксированной width, `preserveAspectRatio="xMidYMid meet"`, минимум path, без фильтров, clipPath и генерируемых ID.
- PNG/ICO рендерятся из SVG в песочнице и кладутся в `public/` как статические файлы корня.
